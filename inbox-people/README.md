# People staging

This folder is retained for temporary research and photograph review. The old `payload.json` package importer has been retired.

Add approved records as separate JSON files under `src/content/people/`, `natural-profiles/`, `appearances/`, and `media/`. Put photographs in `src/content/assets/people/`. Follow [Add a person](../docs/contributing/adding-a-person.md), then run `npm run validate:content`.
