# Hairstyle staging

This folder is retained for temporary research and image-generation outputs. The old `payload.json` package importer has been retired.

Add approved records as separate JSON files under `src/content/hairstyles/`, `sources/`, `style-examples/`, `media/`, and `compatibility/`. Put image files in `src/content/assets/hairstyles/`. Follow [Add a hairstyle](../docs/contributing/adding-a-hairstyle.md), then run `npm run validate:content`.
