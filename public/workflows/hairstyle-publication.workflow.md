# Hairstyle guide and examples

Use this route to research a hairstyle and, when requested, create visual examples.

## Tasks

1. [Hairstyle stub selection](../prompts/hairstyle-stub-selection.prompt.md)
2. [Hairstyle guide research](../prompts/hairstyle-guide-research.prompt.md)
3. [Hairstyle imagery](../prompts/hairstyle-imagery.prompt.md)
4. [Hairstyle example creation](../prompts/hairstyle-example-creation.prompt.md)

## Orchestration

- Start from the named hairstyle, or use stub selection when the request is to choose among existing stubs.
- Research only in-scope styles. Keep unsupported or incomplete guides as stubs; a complete guide may remain draft or be proposed for publication.
- When examples are requested, generate imagery first and create the example from that same image and its Media record. Do not ask the example task to generate another image.
- Results are proposals. The orchestrator reconciles records, checks image/media relationships, and applies them in the available environment.

## Next

Return the guide or continue to imagery and examples when they are part of the request.
